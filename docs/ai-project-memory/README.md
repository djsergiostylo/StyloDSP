# StyloDSP AI Project Memory

This directory is the persistent handoff layer for AI agents working on StyloDSP.

## Entry points

1. `AI_START_HERE.md` at repository root, when present.
2. `docs/AI_MASTER_CONTEXT.md` for the compact project DNA.
3. `harness/INSTRUCTIONS.md` for operating rules.
4. `harness/STATE.md` / `harness/PROJECT_STATE.md` for verified state.
5. Latest audit documents for reconciliation evidence.

## Purpose

Store durable project context, reconciliation rules, decisions, audit evidence and handoff information in GitHub so a new AI can continue the project without relying on a previous ChatGPT conversation.

## Evidence rule

Documentation is not automatically truth. Source, build, runtime and reproducible evidence outrank historical claims. Contradictions must be recorded and resolved explicitly.

## Versioning rule

`V0.x.x` identifies official product versions. Git branches identify development, experiment or archive lines. A branch is not an APK and an APK is not automatically a product version.
