# PROJECT RECONCILIATION PROTOCOL

This is the reusable project-maintenance protocol for StyloDSP.

Canonical operational copy:

`../harness/RECONCILIATION_PROTOCOL.md`

Use it periodically after major development bursts, when multiple AI agents have worked on the project, before releases, or whenever code/documentation state appears inconsistent.

The protocol is intentionally persistent so a future AI can restore project context without relying on historical chat access.
